What this tool checks

One workflow for reviewing suspicious email indicators.

Sender & Authentication

Review sender fields and available SPF, DKIM, and DMARC results.

URLs & Attachments

Inspect extracted links, file fingerprints, and available reputation results.

Received Mail Route

Examine recorded mail hops and IP reputation signals in the analyzed message.

Evidence-based Findings

Bring available indicators together to support a human review, not an automatic guarantee.

How to use it

  1. Provide an emailUpload an .eml file, paste headers, or select a Gmail message.
  2. Run analysisThe backend checks supported email indicators and configured reputation providers.
  3. Review evidenceRead the verdict, findings, URLs, attachments, and the analyzed email's Received chain.
  4. Export if neededDownload the report or JSON for further investigation.

Capabilities

  • .eml and raw-header analysis
  • Read-only Gmail analysis
  • URL and attachment reputation checks
  • Received-chain IP enrichment where available
  • Missing reputation data is marked unknown, not safe
